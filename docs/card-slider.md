# 共通カードスライダー

開始タグに `data-slider="true"` を指定すると有効になります。省略・`false` の場合は従来のグリッドです。1〜6列の開始タグに対応します。

PC（769px以上）ではカードが5枚以上あるときだけスライダーになります。4枚以下は通常のグリッド表示です。SP（768px以下）では枚数に関係なくスライダーになります。画面幅を変更した場合も自動で切り替わります。

```html
<div class="hex-card-grid4-start" data-slider="true"></div>
<!-- 既存の hex-card-start 〜 hex-card-end を必要な枚数配置 -->
<div class="hex-card-grid4-end"></div>
```

CMSでは開始タグ・各カード・終了タグを従来どおりそれぞれのブロックに配置してください。カードの色・画像・本文・リンク・専用クラスはそのまま使えます。

- PC：中央のカードを大きく、左右のカードを縮小表示。その外側のカードは途中まで表示（5枚以上ある場合）。
- SP（768px以下）：通常のカードデザインを等倍・横幅いっぱいで表示します。拡大縮小はせず、横スライドで切り替えます。左右ボタンはカード下のドットナビの両側に配置します。
- 両方：左右ナビ、ドット、左右キー、ドラッグ／スワイプに対応。末尾から先頭へ循環します。
- ドラッグした距離と離す直前の速度に応じて、慣性をつけて減速し、中央のカード位置に収まります。強く払うと複数枚進み、途中で再びつかむこともできます。縦スクロールは通常どおり利用できます。
- 自動送りはありません。カード内の複数画像切り替えとは併用できます。
- カードが1枚の場合はナビを非表示にします。中央のカードのみリンク・キーボード操作を有効にします。
- 動きを減らす端末設定では、拡大アニメーションを省略します。

表示例：`examples/card-slider.html`（PC・SP、通常グリッドを比較できます）。
