# 共通カードスライダー

開始タグの `data-slider-pc`（769px以上）と `data-slider-sp`（768px以下）で、それぞれの動きを指定します。値は `normal`・`vertical`・`horizontal`、PC専用の `scroll` です。端末側の指定を省略・`false` にした場合は通常グリッドになります。1〜6列の開始タグに対応し、画面幅が境界をまたぐと演出も切り替わります。旧属性 `data-slider` は設定に使用しません。

```html
<div class="hex-card-grid1-start" data-slider-pc="vertical" data-slider-sp="horizontal"></div>
<!-- PCは下から、SPは右から入る演出 -->
<div class="hex-card-grid1-end"></div>
```

## 通常の横カルーセル

PC専用の `data-slider-pc="scroll"` は スライダー化前の通常グリッドと同じ幅のカードを、32px間隔で右から左へ自動移動します。位置による拡大縮小は行いません。ドット・左右ボタンは表示しません。カードへのホバー中は移動とサイズ変化が止まり、そのカードがピョコンと跳ねて8px上へ浮きます。キーボードでリンクにフォーカスした間も停止します。画面外・非表示タブでは停止し、動きを減らす端末設定では自動移動しません。PCはカードが5枚以上あると画面外で自然に折り返せます。SPの動きは `data-slider-sp` で別途指定してください。

PC（769px以上）ではカードが5枚以上あるときだけスライダーになります。4枚以下は通常のグリッド表示です。SP（768px以下）では枚数に関係なくスライダーになります。画面幅を変更した場合も自動で切り替わります。

```html
<div class="hex-card-grid4-start" data-slider-pc="normal" data-slider-sp="normal"></div>
<!-- 既存の hex-card-start 〜 hex-card-end を必要な枚数配置 -->
<div class="hex-card-grid4-end"></div>
```

CMSでは開始タグ・各カード・終了タグを従来どおりそれぞれのブロックに配置してください。カードの色・画像・本文・リンク・専用クラスはそのまま使えます。

- PC：中央のカードを大きく、左右のカードを縮小表示。その外側のカードは途中まで表示（5枚以上ある場合）。
- SP（768px以下）：通常のカードデザインを等倍・横幅いっぱいで表示します。カード間の余白は32pxです。拡大縮小はせず、横スライドで切り替えます。左右ボタンはカード下のドットナビの両側に配置します。
- SPのタッチ操作は、少し斜めになった横スワイプも横方向として判定し、操作中はページの縦スクロールを抑制します。明確な上下スワイプはページスクロールへ渡し、複数指の操作ではカード操作を解除してピンチズームを維持します。
- 両方：左右ナビ、ドット、左右キー、ドラッグ／スワイプに対応。末尾から先頭へ循環します。
- PCではドラッグした距離と離す直前の速度に応じて、慣性をつけて減速します。SPは慣性なしで、40px以上スワイプすると隣の1枚へ切り替え、それ未満は元の位置へ戻ります。縦スクロールは通常どおり利用できます。
- 自動送りはありません。カード内の複数画像切り替えとは併用できます。
- カードが1枚の場合はナビを非表示にします。中央のカードのみリンク・キーボード操作を有効にします。
- 動きを減らす端末設定では、拡大アニメーションを省略します。

表示例：`examples/card-slider.html`（PC・SP、通常グリッドを比較できます）。

## お客様向けの2枚のカード（hex-audience-grid）

開始タグに `hex-audience-grid` を付け、2枚のカードそれぞれの `data-title` 内に見出しを記述します。カードの前に別置きしていた見出しは不要です。

```html
<div class="hex-card-grid2-start hex-audience-grid"></div>
<div class="hex-card-start" data-title="<h2 class='hex-top-title hex-top-title-light' data-en='Homeowners'>個人のお客様</h2>外構工事をご検討中の方はこちら"></div>
<!-- 画像・hex-card-end、続いてBusinessesのカードを従来どおり配置 -->
<div class="hex-card-grid2-end"></div>
```

- `data-title` 内の `h2.hex-top-title` を各カードの画像枠へ移動し、後ろの案内文はカード本文側のタイトルとして残します。2枚とも見出しと画像が必要です。
- PC・SPとも白い見出しを画像中央に常時表示し、最初から画像を自動で切り替えます。ホバーやキーボード選択で見出しを隠したり、再生を開始・停止したりする処理はありません。
- PCではカード全体を左は−3度、右は＋3度傾けます。SPでは傾けません。
- PCのカードは列幅の90%で中央配置し、余白と文字サイズも合わせて調整します。文字を含むカード全体の拡縮は行いません。
- SPの `data-slider-sp="horizontal"` では、このクラスだけ通常のカードサイズを維持したまま2枚目を右から1枚目の位置へ重ねます。一般のgrid2～grid6の `horizontal` は従来どおり通常グリッドの各位置へ収まります。見出しの移動はスライダー初期化より前に完了させ、画面幅の切替後も維持します。
- 画像間隔は通常カードと同じ `data-slide-interval`（ミリ秒、既定3000）を使います。画面外・非表示タブでは停止し、端末の「動きを減らす」設定では1枚目を表示します。

## スクロールでカードを順番に配置する

画面下から入れる端末側の属性に `vertical` を指定します。

```html
<div class="hex-card-grid1-start" data-slider-pc="vertical" data-slider-sp="vertical"></div>
<!-- 既存の hex-card-start ～ hex-card-end を必要な枚数配置 -->
<div class="hex-card-grid1-end"></div>
```

画面右端から入れる端末側には `horizontal` を指定します。ページの縦スクロールで進む演出です。`normal` の横カルーセルとは別の機能です。

```html
<div class="hex-card-grid1-start" data-slider-pc="horizontal" data-slider-sp="horizontal"></div>
<!-- 既存の hex-card-start ～ hex-card-end を必要な枚数配置 -->
<div class="hex-card-grid1-end"></div>
```

- grid1は1枚目の固定位置へ後続カードを順番に重ねます。表示枠は最大のカードの高さで、各カードを枠内で下揃えにします。
- grid2～grid6は通常表示と同じ列数・カード幅・高さ・画像サイズ・余白を維持します。画面幅による列数変更も通常表示と共通です。
- 先頭カードを固定し、2枚目以降が `vertical` では画面下、`horizontal` では画面右から順番に入ります。grid2～grid6では通常グリッドの各配置先へ収まります。最後のカードで固定が外れ、次のコンテンツへ進みます。逆方向にも通常スクロールで戻れます。
- 自動送り、循環、ドラッグ操作はありません。
- 固定位置は1枚目のカードの高さ中央と、ヘッダー下端から画面下端までの中央を揃えます。その前にカード上端がヘッダー下端へ届く高さの場合は、カード上端とヘッダー下端を揃えます。PC・SPとも同じルールで、ヘッダーの高さは各画面幅のCSS指定から取得します。
- 複数段でも全体を1枚目の固定位置に留めます。2段目以降への自動移動は行いません。画面に収まらない下段は、固定解除後の通常スクロールで確認できます。
- 後続カードは指定方向の画面端の外で待機します。grid2～grid6では1枚が配置先へ収まってから次のカードが入ります。
- SPの `horizontal` は、固定枠が画面下端まで届く高さを確保します。カードより下の領域は所属範囲の背景色で表示し、その高さも固定解除と後続コンテンツの配置計算に含めます。
- SPの横移動中は、同じ画面幅での再計測によって固定位置・移動距離を変更しません。Safariのツールバー等による高さ変化では背景の高さだけ更新し、その他の再計測は固定区間を出てから行います。画面幅の変更・回転時はその場で再計測します。
- SPの横移動中の枠は `position:fixed` で画面に直接固定し、最後のカードが収まると `sticky` に戻して次のオーバーラップへ引き継ぎます。固定を保つための逆方向の移動補正は行いません。PC・縦移動は従来の `sticky` のままです。
- 所属するCMSセクション（通常HTMLではsection）のうち、カードより前の内容も1枚目の固定時点の位置に留めます。カードより後の本文やボタンは固定範囲から外し、最後のカードに隙間なく続く通常フローに配置します。元からある余白は維持します。
- PCの `vertical` では、同じセクション内に続くコンテンツがある場合、最後のカードが収まった時点で続きの先頭が画面下端に来るよう固定区間を延長します。続きが下から上がって通常の配置につながるまでカードを固定し、その後は一緒にスクロールします。カード下端が画面下に見切れる高さの場合は延長しません。
- 直前のセクションも1枚目の固定開始から最後のカードまで位置を維持し、最後で解除します。ページ内の他の演出で配置が変わっても、カードの進行位置は現在の枠の位置から求めます。
- 次のセクションにオーバーラップがある場合は、カード演出の完了後に所属セクション全体を背面の固定対象へ引き継ぎます。カード内部の固定枠をさらに包むことはせず、次の重なりがカード演出より先に始まらないようにします。
- セクションごとに1つの縦カードグループを使用してください。同じセクションの追加グループは通常のグリッド表示になります。
- 動きを減らす端末設定では、固定や移動をせず通常のグリッド表示になります。
- CMSの外枠には既存の共通クラスで切り抜き解除を適用します。独自の外枠のoverflowやtransformは固定に影響する場合があります。

表示例：`examples/card-slider.html` の「縦スライド」。
